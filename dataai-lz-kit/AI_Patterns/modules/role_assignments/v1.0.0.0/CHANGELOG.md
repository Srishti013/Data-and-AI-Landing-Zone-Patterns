## [1.0.0.0] - Initial Release

### Added

- Create Azure Role Assignments Terraform Module.
- Support for role assignments at multiple scopes (Entra ID, Management Group, Subscription, Resource Group, Resource).
- Support for multiple principal types (User, Group, App Registration, System/User Assigned Managed Identity).
- Built-in and custom role definition support.
- Telemetry integration.
